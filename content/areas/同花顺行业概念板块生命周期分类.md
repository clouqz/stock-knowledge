## 术语速查表

> 本表前置以便快速查阅，详细解释见5.12名词解释

| 术语               | 含义                                                       | 关键阈值/要点                                      |
| ------------------ | ---------------------------------------------------------- | -------------------------------------------------- |
| CR4                | 行业前4名企业市场份额之和                                  | 成熟期≥50%；衰退期<40%且同比降≥5pct                |
| 渗透率             | 产品/技术在目标市场的采用比例                              | 成熟期>60%（存量竞争50-60%）；衰退期从峰值降≥5pct  |
| 方差判定           | 过去4Q营收增速方差判定稳定/波动                            | 稳定≤3pct；波动>5pct；灰色3-5pct按CR4判定          |
| 存量竞争           | 行业总需求不再增长，竞争转向份额争夺                       | 满足其一：渗透率环比<1%/销量同比<5%/产能利用率<75% |
| 高增豁免           | 渗透率<20%时，按CR4梯度放宽增速归成长期                    | CR4 20-30%+≥25%；30-40%+≥35%；40-50%+≥50%          |
| 技术迭代快豁免     | 技术迭代快+渗透率≤25%+增速≥20%波动→CR4可放宽至<30%归初创期 | 满足其一：研发占比≥15%/迭代周期≤12月/专利新增≥20%  |
| 寡头格局           | CR3>70%或CR4>80%                                           | 增速≥30%仍归成熟期                                 |
| CR4 40-50%边界规则 | CR4 40-50%时渗透率是分水岭                                 | <20%→可触发高增豁免；≥20%→直接归成熟期             |
| 强出口型行业       | 出口营收占比≥30%                                           | 出口增速连续2Q>20%可豁免存量竞争判定               |
| 稳定盈利行业豁免   | 业务模式稳定+现金流强的行业                                | CR4>40%+增速>-5%→豁免毛利率-5pct+要求              |
| 强现金流行业       | 经营性现金流/营收≥15%                                      | 公用事业/物业管理/高速公路/仓储物流等              |
| 存量竞争出口豁免   | 强出口型行业出口增速>20%(连续2Q)                           | 仅豁免存量竞争，渗透率仍需50-60%+CR4≥50%           |
| 突发政策基数       | 国家级政策+CR4单季度降幅≥3pct                              | 峰值CR4-当前CR4≥5pct即可触发衰退期                 |

## 快速判定卡

> 无豁免情形下的基础判定规则（≤1页），高级规则（豁免/边界）详见正文

**第一步：营收增速定性**

| 增速特征 | 方差判定    | 初步归属 |
| -------- | ----------- | -------- |
| >30%     | 波动(>5pct) | 初创期   |
| 20-30%   | 稳定(≤3pct) | 成长期   |
| 5-10%    | -           | 成熟期   |
| 负增长   | -           | 衰退期   |

**第二步：CR4验证**

| 阶段   | CR4要求             | 不满足时                 |
| ------ | ------------------- | ------------------------ |
| 初创期 | <20%                | → 成长期                 |
| 成长期 | 20-40%              | <20%→初创期；>40%→成熟期 |
| 成熟期 | ≥50%                | <50%→成长期              |
| 衰退期 | <40%且同比降≥5pct\* | 未降≥5pct→成熟期         |

\* 衰退期CR4同比降幅基于近2年均值，详见正文

**第三步：渗透率确认**

| 阶段   | 渗透率要求             | 不满足时        |
| ------ | ---------------------- | --------------- |
| 初创期 | <10%                   | -               |
| 成长期 | 10-40%                 | -               |
| 成熟期 | >60%（存量竞争50-60%） | <60%→成长期     |
| 衰退期 | 从峰值下降≥5pct        | 不足5pct→成熟期 |

**冲突时优先级**：特殊规则 > 渗透率 > CR4 > 营收增速

> 遇到豁免/边界/冲突情形，参见正文「指标执行补充说明」「跨指标冲突判定流程」「5.3特殊规则使用说明」

### 指标执行补充说明

| 阶段   | 核心指标             | 阈值说明                                        | 特殊情形规则                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | 辅助判定标准                          |
| ------ | -------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| 初创期 | 营收增速 >30% 波动   | CR4<20%，渗透率<10%，毛利率高但不稳定（>40%）   | 部分赛道（如消费电子、互联网电商）因技术迭代快、格局分散，营收增速≥20%波动也可归入初创期；**渗透率豁免规则**：技术迭代快/格局极度分散的赛道，渗透率≤25%且营收增速≥20%波动+CR4<30%，可豁免归初创期；**注意**：初创期CR4基础阈值<20%；仅当满足「技术迭代快+渗透率≤25%+营收增速≥20%波动」时，CR4可放宽至<30%（20-30%区间仅豁免场景归初创，否则归成长）；**「技术迭代快」量化定义**：满足以下其一即可：①研发投入占比≥15%；②产品迭代周期≤12个月；③专利新增数同比≥20%（统计周期：近12个月；统计范围：行业市值前10企业）（如消费电子渗透率<20%+增速>25%波动+CR4<20%+研发占比18%→技术迭代快→豁免归初创；互联网电商渗透率<25%+增速>20%波动+CR4<30%+迭代周期9个月→技术迭代快→豁免归初创） | 波动=季度增速方差>5pct；毛利率高=40%+ |
| 成长期 | 营收增速 20-30% 稳定 | CR4 20-40%，渗透率 10-40%，毛利率稳定（25-35%） | **分层定义**：核心期(渗透率10-20%+CR4 20-30%→增速20-30%)、中后期(渗透率20-40%+CR4 30-40%→增速10-20%)；**高增豁免梯度表**（渗透率<20%前提下）：                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

| CR4区间 | 渗透率前提 | 增速阈值 | 无上限 | 归属               | 边界规则                            |
| ------- | ---------- | -------- | ------ | ------------------ | ----------------------------------- |
| 20-30%  | <20%       | ≥25%     | 是     | 成长期             | -                                   |
| 30-40%  | <20%       | ≥35%     | 是     | 成长期             | -                                   |
| 40-50%  | <20%       | ≥50%     | 是     | 成长期             | 渗透率≥20%→直接归成熟期（无论增速） |
| >50%    | 无         | -        | -      | 无豁免（归成熟期） | 除非满足存量竞争豁免                |
| <20%    | -          | -        | -      | 归初创期           | -                                   |

**毛利率豁免**：高增豁免触发时毛利率可放宽（不强制25-35%），标注为「较高/高」即可（如CXO毛利率40%+归成长期）

**成长期分层与豁免关系说明**：

| 分层   | 渗透率 | CR4    | 增速   | 是否适用高增豁免                   | 毛利率标准                                      | 稳定性判定                                |
| ------ | ------ | ------ | ------ | ---------------------------------- | ----------------------------------------------- | ----------------------------------------- | --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 核心期 | 10-20% | 20-30% | 20-30% | 适用（渗透率<20%前提满足）         | 稳定(25-35%)；高增豁免触发时可放宽至「较高/高」 | 方差≤3pct→稳定                            |
| 中后期 | 20-40% | 30-40% | 10-20% | 不适用（渗透率≥20%不满足豁免前提） | 稳定(25-35%)                                    | 方差≤3pct→稳定；灰色地带(3-5pct)按CR4判定 |     | 稳定=过去4个连续季度营收增速方差≤3pct（方差计算基数：季度增速的百分比点数，如25%/24%/26%/25%→方差=0.5个百分点）；波动=方差>5pct；灰色地带(3-5pct)：CR4<20%→波动(初创)，CR4≥20%→稳定(成长)；**补充**：渗透率<10%时无论CR4高低，灰色地带均归波动(初创)，因极低渗透率本身暗示行业不成熟；**方差异常修正**：若某季度受突发因素扰动可剔除，用剩余3季度重新计算，3Q方差阈值=原阈值×1.2（稳定≤3.6pct、波动>6pct、灰色3.6-6pct）；**突发因素定义**：①疫情（区域封控≥1个月）；②政策（行业性补贴/限产政策）；③自然灾害（全国性自然灾害如洪涝/地震影响行业产能≥10%）；④供应链中断（行业性供应链中断≥1个月，如芯片断供）；**验证数据源优先级**：①工信部/统计局等官方发文；②行业协会（如中国光伏行业协会/中国汽车工业协会）报告；③同花顺行业板块财报汇总数据 |

| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| 基础规则           | CR4<40% 且 近2年均值同比降≥5pct                                                                                                                                                          | 平滑短期波动，基数取近2年均值                           |
| 豁免规则(突发政策) | ①触发条件：国家级政策（国务院/部委发文）+CR4单季度降幅≥3pct；②基数取值：政策发布前3个季度CR4最大值→无则取近5年最大值；③判定阈值：峰值CR4-当前CR4≥5pct即可触发，无需再算近2年均值同比降幅 | 如"三道红线"导致地产CR4单季度降4pct→可采用峰值CR4为基数 |

**渗透率下降阈值**：从峰值下降≥5pct触发衰退期判定（如峰值70%→当前60%，-10pct≥5pct）；**衰退期判定失败规则**：若CR4未达<40%或同比降幅不足5pct，且渗透率从峰值下降<5pct，即使存在渗透率下降也不强制归衰退期，仍维持成熟期（例：CR4=45%（略高于40%）+营收增速-1%+渗透率从峰值下降4pct→不满足衰退期CR4条件→归成熟期）；**毛利率豁免**：强现金流行业(公用事业/物业管理/高速公路/仓储物流)，若CR4>40%且营收增速>-5%，毛利率可标注"稳定"；**衰退期毛利率判定口径**：「<20%」= 近4季度均值<20%或同比下降≥8pct；**强现金流量化定义**：经营性现金流/营收≥15%（如高速公路经营性现金流/营收=22%≥15%→强现金流→豁免毛利率<20%要求，毛利率≥20%即可归衰退期） | 渗透率标注格式：峰值XX%(YYYY年)→当前XX%(2026Q1)，-XXpct；渗透率从峰值下降≥5pct为衰退期触发条件；**峰值定义**：取行业生命周期内渗透率最大值，判定优先级：①行业生命周期明确的（如新能源汽车）取生命周期最大值；②无明确周期的（如房地产/公用事业）取近10年最大值；③新兴行业（如储能）取近5年最大值，标注峰值年份 |
| 统一标注 | CR4/CR3 | 优先CR4，寡头格局特殊标注CR3 | 寡头格局定义：CR3>70%或CR4>80%，标注格式「CR4=XX%（CR3=XX%，口径：XX）」 | 所有CRn数据需标注计算口径（营收/出货量/市值） |

### 跨指标冲突判定流程

当行业指标出现冲突时（如营收增速25%+CR4=55%+渗透率55%），按以下优先级判定：

1. **特殊规则优先**：存量竞争、寡头格局豁免、稳定盈利行业豁免、成长期高增豁免、初创期技术迭代快豁免
2. **多豁免同时满足时的优先级**：初创期技术迭代快豁免 > 成长期高增豁免（因初创期更强调技术不确定性，技术迭代快是行业尚未定型的根本性特征，优先级高于单纯增速高增）
3. **其次看渗透率**：成熟期>60%/衰退期从峰值下降
4. **再看CR4**：成熟期≥50%/衰退期<40%且同比降5pct+
5. **最后看营收增速**：初创>30%/成长20-30%/衰退负增长

### 分类优先级场景说明

- **长期产业趋势（>3年）**：使用行业板块分类
- **短期商业化节奏（<1年）**：使用概念板块分类
- **中周期（1-3年）**：结合两者，成长/成熟期概念优先，初创/衰退期行业优先

### 分类口径说明

- **行业板块**：反映行业整体属性（如游戏：研发投入高、盈利波动大，归初创期）
- **概念板块**：反映商业化进程（如游戏：精品化+出海驱动商业化提速，归成长期）
- **差异说明**：同一标的在行业板块和概念板块的分类可能不同，因分析维度不同
- **优先级说明**：投研分析中，行业板块分类用于长期产业趋势判断，概念板块分类用于短期商业化节奏把握；同一标的出现跨阶段分类时，优先参考行业板块分类，概念板块作为弹性补充
- **CRn标注规则**：统一标注为CR4，寡头格局（CR3>70%或CR4>80%，如动力电池CR3>76%）特殊标注，标注格式统一为「CR4=XX%（CR3=XX%，口径：XX）」，标注计算口径（出货量/营收/市值）

**衰退期边界规则：判定失败回到成熟期**

当行业部分指标符合衰退期特征但不完全满足时，按下表判定：

| 场景            | 条件                                                  | 判定结果   | 说明                                              |
| --------------- | ----------------------------------------------------- | ---------- | ------------------------------------------------- |
| CR4不满足       | CR4≥40%（未达<40%）+营收负增长+渗透率从峰值下降       | 维持成熟期 | CR4≥40%说明集中度未下降至衰退水平，行业格局仍稳固 |
| CR4同比降幅不足 | CR4<40%但同比降幅<5pct+营收负增长+渗透率从峰值下降    | 维持成熟期 | 集中度下降趋势尚未确立，可能是短期波动            |
| 渗透率下降不足  | 营收负增长+CR4<40%且同比降≥5pct+渗透率从峰值下降<5pct | 仍归衰退期 | CR4和营收已满足衰退条件，渗透率下降不足不构成排除 |
| 全部不满足      | CR4≥40%+同比降幅<5pct+渗透率下降<5pct                 | 维持成熟期 | 无衰退期核心指标支撑                              |

### 4.2 行业配置建议

**初创期（谨慎配置）**：

- 半导体（先进制程）、固态电池、量子通信、人形机器人
- 策略：仓位不超过10%，等待技术路线明确

**成长期（重点配置）**：

- 储能、军工（航空航天）、创新药、CXO
- 数字经济（信创、AI应用）、半导体（国产替代）

- 银行、电力、运营商、白酒
- 新能源汽车（存量竞争）、光伏（产能出清）、动力电池（寡头格局）
- 策略：仓位20-30%，高股息策略

**衰退期（回避或择时）**：

- 房地产、养殖业、传统零售
- 策略：仓位<5%，仅关注困境反转

### 4.3 风险提示

1. 本分类基于行业特性推断，实际投资需结合具体公司财务数据
2. 行业生命周期阶段可能因技术突破、政策变化等因素发生迁移
3. 初创期行业波动大，需密切关注技术路线和商业化进程

## 五、分类使用注意事项

### 5.1 投研应用优先级

- **行业板块分类**：用于长期产业趋势判断，投研决策优先参考
- **概念板块分类**：用于短期商业化节奏把握，作为弹性补充
- **跨阶段分类**：同一标的在行业板块和概念板块分类不同时（如游戏），优先参考行业板块分类
- **跨板块差异投研指引**：
- 长期配置（>3年）：行业板块权重80%+概念板块20%，严格参考行业板块
- 短期交易（<1年）：概念板块权重70%+行业板块30%，侧重概念板块
- 中周期（1-3年）：行业板块权重60%+概念板块40%，行业板块定方向，概念板块定弹性

**跨板块综合评级**：

当同一标的在行业板块和概念板块分类不同时，采用「综合评级」标注，格式为「长期XX期（行业板块），短期XX期（概念板块）」：

| 标的     | 行业板块 | 概念板块 | 综合评级                           | 调仓触发条件                                                    |
| -------- | -------- | -------- | ---------------------------------- | --------------------------------------------------------------- |
| 游戏     | 初创期   | 成长期   | 长期谨慎（初创），短期积极（成长） | 当行业板块CR4升至20%+增速稳定→行业板块调整为成长期→综合评级升级 |
| 消费电子 | 初创期   | 成长期   | 长期谨慎（初创），短期积极（成长） | 当渗透率突破20%+格局稳定→行业板块评估调整                       |
| 军工电子 | 初创期   | 成长期   | 长期谨慎（初创），短期积极（成长） | 当订单增长持续4Q+CR4升至20%→行业板块评估调整                    |
| 物流     | 成长期   | 成熟期   | 长期积极（成长），短期稳健（成熟） | 当渗透率突破50%+CR4>50%→行业板块评估调整为成熟期                |

**跨板块分类应用操作指南**：

| 投资周期       | 核心参考                      | 弹性补充             | 操作规则                                                                                                           | 典型案例                                                                            |
| -------------- | ----------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| 长期投资(>3年) | 行业板块分类                  | 概念板块作为风险边界 | 完全按行业板块分类操作；概念板块若高于行业板块阶段（如游戏：行业=初创，概念=成长），概念板块仅用于判断短期催化风险 | 游戏：长期按初创期策略（仓位≤10%），概念板块"成长期"仅作短期催化提示                |
| 短期交易(<1年) | 概念板块分类                  | 行业板块作为风险边界 | 以概念板块分类为核心交易依据；行业板块若低于概念板块阶段，作为止损/风控信号                                        | 消费电子：短期按概念板块"成长期"交易，但行业板块"初创期"提示仓位上限≤30%            |

### 5.2.3 行业生命周期简易评分卡

> 供分析师快速计算，辅助判定行业所处阶段（分数越高越接近成熟期/衰退期）

| 指标     | 初创期(1分) | 成长期(2分) | 成熟期(3分) | 衰退期(4分)   | 得分  |
| -------- | ----------- | ----------- | ----------- | ------------- | ----- |
| 营收增速 | >30%波动    | 20-30%稳定  | 5-10%       | 负增长        | \_    |
| CR4      | <20%        | 20-40%      | ≥50%        | <40%且降≥5pct | \_    |
| 渗透率   | <10%        | 10-40%      | >60%        | 从峰值降≥5pct | \_    |
| 毛利率   | >40%        | 25-35%      | 同比-5pct+  | <20%          | \_    |
| **总分** | -           | -           | -           | -             | \_/16 |

> **判定参考**：4-6分→初创期倾向；7-10分→成长期倾向；11-13分→成熟期倾向；14-16分→衰退期倾向
> **注意**：本评分卡仅为基础辅助工具，当分数处于边界区间（如10-11分）时，以冲突判定优先级为准（特殊规则>渗透率>CR4>营收增速），评分卡仅作参考；触发豁免/存量竞争等特殊规则时，评分卡结果可能偏离实际分类，需按详细规则重新判定
> **边界示例**：某行业总分11分（成熟期倾向），但渗透率仅15%（成长期特征）且CR4=30%（成长期），特殊规则无触发→按优先级（渗透率>CR4>营收增速）→渗透率15%属成长期区间→最终归成长期（评分卡11分"成熟期倾向"被推翻）

### 5.5 分类复核清单

投研使用前需逐项核对以下6项内容：

1. **指标覆盖性**：检查是否覆盖最新季度数据（如2026Q1），核心指标（营收增速/渗透率/CR4/毛利率）是否完整
2. **特殊规则标注**：检查是否标注豁免/存量竞争/寡头格局/过渡阶段，规则触发说明列是否填写
3. **冲突判定优先级**：当指标冲突时，验证是否按优先级判定（特殊规则>渗透率>CR4>营收增速），是否正确触发豁免/边界规则
4. **口径统一性**：检查CR4/CR3是否标注计算口径（营收/出货量/市值）+数据来源，CR4≥40%时是否补充CR3，寡头格局（CR3>70%或CR4>80%）是否按统一格式标注
5. **跨板块差异**：检查行业板块与概念板块分类是否一致，不一致时是否标注「跨板块差异：行业板块=XX期，概念板块=XX期」及投研权重
6. **渗透率/毛利率量化**：检查渗透率是否按阶段格式标注（初创期<XX%/成长期XX-XX%/成熟期>XX%/衰退期峰值→当前），毛利率"稳定"是否满足区间25-35%且同比波动≤5pct

**分类复核清单落地模板**：

| 字段            | 内容                                    | 说明                                                |
| --------------- | --------------------------------------- | --------------------------------------------------- |
| 行业名称/代码   | 如"储能电池/8842"                       | 同花顺行业代码                                      |
| 核心指标        | 营收增速/CR4/渗透率/毛利率              | 需标注数据来源（同花顺/工信部/第三方）              |
| 规则触发项      | 是否触发豁免/存量竞争/寡头格局/过渡阶段 | 对应规则触发说明列                                  |
| 跨板块分类      | 行业板块=XX期，概念板块=XX期            | 不一致时标注权重（长期80/20、中期60/40、短期30/70） |
| 复核人/复核日期 | 姓名/2026Q1                             | 季度更新后复核                                      |
| 异常说明        | 数据缺失/规则冲突/方差异常              | 如"Q2受疫情扰动剔除后方差=1.2≤3pct→稳定"            |

**典型案例说明**：

- 风电设备：海上风电→初创期（新技术，商业模式待验证）；陆上风电→成长期（装机增长）
- 游戏：行业板块→初创期（研发投入高、盈利波动大）；概念板块→成长期（精品化+出海驱动）
- 动力电池：成熟期（CR3>76%寡头格局，增速30%+但基数大体量大）

| CR4>65%增速放宽         | 成熟期        | CR4>65%+存量竞争                           | 存量竞争条件之一+增速连续2Q放缓+毛利率同比-5pct+           | 增速可放宽至20-30%                                                               | 按成熟期规则            |
| 寡头格局豁免            | 成熟期        | CR3>70%或CR4>80%                           | 增速≥30%，标注格式「CR4=XX%（CR3=XX%，口径：XX）」         | 仍归成熟期                                                                       | 按成熟期规则            |
| 衰退期CR4基数(常规)     | 衰退期        | 常规情形                                   | CR4<40%且近2年均值同比降≥5pct                              | 归衰退期                                                                         | 按衰退期规则            |
| 衰退期CR4基数(突发政策) | 衰退期        | 突发政策(国家级政策+CR4单季度降幅≥3pct)    | 峰值CR4-当前CR4≥5pct即可触发，无需再算近2年均值            | 可用峰值CR4为基数归衰退期（**峰值取值**：政策发布前3Q最大值，无则取近5年最大值） | 按衰退期规则            |
| 稳定盈利行业豁免        | 成熟期/衰退期 | CR4>40%+营收增速>-5%+业务模式稳定/现金流强 | 毛利率稳定≥20%                                             | 豁免"毛利率同比-5pct+"要求                                                       | 标注"稳定"              |

#### 5.3.0 多豁免同时满足时的优先级规则

当行业同时满足多种豁免/特殊规则时，按以下优先级判定：

| 优先级    | 豁免类型             | 判定结果 | 原因                                                                                   |
| --------- | -------------------- | -------- | -------------------------------------------------------------------------------------- |
| 1（最高） | 初创期技术迭代快豁免 | 归初创期 | 技术迭代快是行业尚未定型的根本性特征，优先级高于单纯增速高增；初创期更强调技术不确定性 |
| 2         | 成长期高增豁免       | 归成长期 | 仅当不满足技术迭代快豁免时适用                                                         |
| 3         | 存量竞争判定         | 归成熟期 | 仅当不满足上述初创/成长期豁免时适用                                                    |

**跨阶段豁免冲突规则**：

| 冲突场景                   | 优先规则           | 判定结果 | 原因                                                                                                   |
| -------------------------- | ------------------ | -------- | ------------------------------------------------------------------------------------------------------ |
| 技术迭代快豁免 vs 高增豁免 | 技术迭代快豁免优先 | 归初创期 | 技术迭代快是行业未定型的根本特征，高于增速高增                                                         |
| 技术迭代快豁免 vs 存量竞争 | 技术迭代快豁免优先 | 归初创期 | 存量竞争仅在行业进入成熟期后才适用，技术迭代快表明行业尚未定型，两者冲突时优先采用更底层的行业属性判断 |
| 高增豁免 vs 存量竞争       | 高增豁免优先       | 归成长期 | 渗透率<20%且增速超阈值说明行业仍处高速扩张期，存量竞争条件（如渗透率环比<1%）在低渗透率下不可靠        |

**判定流程**：

1. 先检查是否满足「技术迭代快」（研发占比≥15%或迭代周期≤12月或专利新增≥20%）
2. 若满足技术迭代快 + 渗透率≤25% + 增速≥20%波动 → 归初创期（无论CR4是否也满足高增豁免或存量竞争条件）
3. 若不满足技术迭代快，再检查高增豁免梯度表
4. 若不满足上述初创/成长期豁免，最后检查存量竞争/寡头格局等成熟期规则

**典型案例**：

- **案例1**：某行业增速22%波动、CR4=25%、渗透率18%、研发占比16%
  - 满足技术迭代快豁免：研发占比16%≥15% + 渗透率18%≤25% + 增速22%≥20%波动 → 归初创期
  - 也满足高增豁免前提：渗透率18%<20% + CR4=25%在20-30%，但增速22%<25%不满足梯度①
  - **结果**：技术迭代快豁免优先 → 归初创期

- **案例2**：某行业增速22%波动、CR4=28%、渗透率18%、研发占比16%、渗透率环比0.8%<1%
  - 同时满足技术迭代快豁免（归初创期）和存量竞争条件（渗透率环比<1%，通常用于成熟期）
  - **结果**：技术迭代快豁免优先 → 归初创期（存量竞争仅在行业进入成熟期后才适用，技术迭代快表明行业尚未定型）

#### 5.3.1 技术迭代快判定规则

| 维度     | 规则                                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------------- |
| 统计周期 | 近12个月                                                                                                             |
| 统计范围 | 行业市值前10企业                                                                                                     |
| 触发条件 | 满足以下其一即可：①研发投入占比≥15%；②产品迭代周期≤12个月；③专利新增数同比≥20%                                       |
| CR4口径  | 基础阈值<20%；仅当「技术迭代快+渗透率≤25%+增速≥20%波动」时CR4可放宽至<30%（20-30%仅豁免归初创，否则归成长）          |
| 典型案例 | 消费电子：研发占比18%→技术迭代快→渗透率<20%豁免归初创期；互联网电商：迭代周期9个月→技术迭代快→渗透率<25%豁免归初创期 |

### 5.4 数据口径说明

- **CR4口径**：制造类（电力设备、机械设备、汽车）默认CR4（出货量口径，国内头部4家出货量占比）；消费/金融/服务类默认CR4（营收口径，全球头部4家营收占比）；军工/通信类默认CR4（营收口径，国内头部4家营收占比）；所有CRn需标注计算口径（营收/出货量/市值）及统计范围（国内/全球），寡头格局（如动力电池CR3>76%）补充"CR3>XX%（CR4>XX%）"格式
- **CR4口径优先级**：①制造型行业（动力电池、光伏、风电等）→出货量优先；②服务型行业（电商、IT服务、金融等）→营收优先；③未上市为主行业（初创期部分赛道）→市值（估值）优先
- **混合行业CRn计算规则**：环保等拆分行业，按细分赛道分别计算CRn，标注「CR4=XX%（细分：XX，口径：XX）」（如环保运营端CR4>50%(营收) vs 环保设备端CR4 25-40%(营收)）；寡头标注示例：「CR4=82%（CR3=75%，口径：出货量）」
- **CRn统一标注要求**：所有行业（含成长期）均需标注CR4数值+计算口径（如"CR4 25-40%(营收)""CR4 30-45%(出货量)"）；仅标注范围无具体数值时需补充数据来源标注（如"CR4 30-45%(营收，同花顺2026Q1)"）
- **CRn数据来源标注**：所有CRn数据需标注来源（如"CR4 30-45%(营收，同花顺2026Q1)""CR3>76%(出货量，SNE Research 2026Q1)"），数据来源优先级：①同花顺行业数据库；②第三方机构（SNE Research/CPIA/灼识咨询）；③上市公司财报汇总
- **CR4无官方数据时的替代方案**：若无权威CR4数据，可用同花顺行业板块市值TOP4企业营收/出货量占比测算（标注"CR4测算=XX%(营收，同花顺TOP4推算)"），制造型用出货量口径，服务型用营收口径
- **CR4数据获取分级方案**：

| 数据级别          | 数据来源                                                | 标注要求                                                            | 优先级 |
| ----------------- | ------------------------------------------------------- | ------------------------------------------------------------------- | ------ |
| Level 1（优先）   | 官方/权威第三方CR4（SNE Research、CPIA、中汽协、IDC等） | 需注明来源机构+发布时间（如"CR3>76%(出货量，SNE Research 2026Q1)"） | 最高   |
| Level 2（可接受） | 同花顺行业板块市值TOP4的营收/出货量占比推算             | 标注"测算值"+推算口径（如"CR4测算=35%(营收，同花顺TOP4推算)"）      | 次之   |
| Level 3（备选）   | 公开研报或券商估算值                                    | 标注来源券商+研报日期（如"CR4=40%(营收，中信证券2026年3月研报)"）   | 最低   |

> **冲突处理**：若Level 1数据与Level 2/3冲突，以Level 1为准；Level 2与Level 3冲突，以Level 2为准

- **装机/销量驱动型行业替代指标**：光伏/风电等装机驱动型行业，可用「装机量增速」替代「营收增速」作为核心判定指标（如光伏设备：2026Q1全国新增装机同比-31%→等效营收增速负增长）；新能源汽车/动力电池等销量驱动型行业，可用「销量增速」替代（标注"装机量增速=XX%(同比)"或"销量增速=XX%(同比)"）
- **分指标数据源优先级**：
- 渗透率：①工信部/统计局官方数据 > ②行业协会（如中国光伏行业协会/中国汽车工业协会）> ③第三方机构（IDC/赛迪/灼识咨询）> ④同花顺测算
- CR4/CR3：①上市公司财报汇总（同花顺/SNE Research）> ②行业白皮书（CPIA/SNE）> ③券商研报 > ④同花顺TOP4推算
- 营收增速：①同花顺行业板块数据 > ②上市公司财报加权 > ③行业协会统计
- **无权威数据标注规则**：使用测算值时标注「测算值」+说明测算逻辑（如"渗透率测算=销量/潜在市场空间，潜在空间取XX机构预测"）

> **测算值标注**：当渗透率分母无法精确定义时（如IT服务、软件开发、通信服务等），采用「行业营收/潜在市场空间」测算，标注「渗透率测算=行业营收/潜在市场空间（潜在空间取XX机构预测，测算值）」；2.1/2.2表中标注为「<XX%」的区间估值若无权威数据支撑，统一视为测算值；**替代观测指标**：标注为「测算值」的行业，若「潜在市场空间」数据难以获取，可改用替代观测指标跟踪渗透率变化趋势（如IT服务→信创营收/IT总营收），本分类中渗透率<XX%仅作定性参考，不要求精确计算；**替代观测指标使用原则**：替代观测指标主要用于跟踪渗透率变化方向（环比/同比趋势），不要求精确数值；若替代指标数据亦无法获取，仍以定性判断为主

- **CRn双标注触发条件**：当CR4≥40%且CR3≥30%时，需同时标注CR3（如白酒CR4 40-55%，补充CR3 30-45%；航空装备CR4 35-50%(营收)，补充CR3 25-35%）
- **毛利率**：数值型标注（如26-27%、40%+），定性标注参照量化表；毛利率稳定 = 区间25-35% 且 同比波动≤5pct；若区间在25-35%但同比波动>5pct，需标注"毛利率区间达标但波动超标"
- **毛利率标注格式规范**：统一采用「区间+定性」格式，如"25-35%(稳定)""35-40%(较高)""26-27%(稳定，同比波动≤5pct)"；特殊值需补充波动说明
- **毛利率「同比」基准说明**：「同比」指与上年同期对比（如2026Q1 vs 2025Q1）；若遇异常年份（如疫情影响），可参考「较2023年同期」或使用2年复合增速（CAGR）；异常年份定义：行业毛利率受疫情/政策/自然灾害等突发事件影响，单季度偏离近4Q均值超过10pct的年份

**毛利率标注量化对照表**：

| 标注词 | 毛利率区间 | 适用阶段           | 说明                                          |
| ------ | ---------- | ------------------ | --------------------------------------------- |
| 高     | >40%       | 初创期/成长期豁免  | 初创期基础规则；成长期高增豁免时也可标注      |
| 较高   | 35-40%     | 成长期豁免         | 成长期高增豁免触发时毛利率超标可标注          |
| 中高   | 30-40%     | 初创期             | 初创期部分赛道（如消费电子）                  |
| 稳定   | 25-35%     | 成长期（基础规则） | 成长期核心毛利率区间，需同时满足同比波动≤5pct |
| 下降   | 同比-5pct+ | 成熟期             | 毛利率从高位下降，同比降幅≥5个百分点          |
| 压缩   | <20%       | 衰退期             | 毛利率被严重压缩                              |

- **渗透率标注规范**（统一补充时间口径）：
- **所有阶段统一要求**：渗透率均需标注当前值及时间口径（如2026Q1），便于后续跟踪；衰退期严格标注峰值年份
- 初创期：「<XX%(2026Q1)」或特殊豁免值（如消费电子「<20%(2026Q1)」需备注豁免原因）
- 成长期：「XX-XX%(2026Q1)」（如10-25%(2026Q1)、15-30%(2026Q1)）；无区间则标「<XX%(2026Q1)」
- 成熟期：「XX-XX%(2026Q1)」或下限「>XX%(2026Q1)」；存量竞争场景补充判定（如「渗透率55%(2026Q1)，环比0.8%→存量竞争」）
- 衰退期：严格按「峰值XX%(YYYY年)→当前XX%(2026Q1),-XXpct」格式（YYYY为自然年）
- **规则触发说明**：行业板块表格末列标注是否触发特殊规则（豁免/存量竞争/寡头格局/过渡阶段/跨板块差异），便于快速定位。跨板块差异统一格式为「跨板块差异：行业板块=XX期，概念板块=XX期」

### 5.7 过渡阶段判定规则

当行业指标处于两个阶段的边界时，按下表量化判定：

| 过渡类型                | 触发条件                                                       | 归类规则                                                                    | 投研使用建议                                                               | 典型行业                                                                                          |
| ----------------------- | -------------------------------------------------------------- | --------------------------------------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 成长后期→成熟期         | 渗透率45-65% + CR4 45-60% + 营收增速5-15% + 毛利率同比-3~-5pct | 仍归成长期，但标注"成长后期→成熟期过渡"；若增速连续2Q<10%，调整为成熟期     | 长期按成熟期估值（股息率/现金流），短期按成长期交易（营收增速/渗透率提升） | 白色家电(渗透率45-65%+CR4 45-60%)、保险(CR4 45-60%+渗透率35-55%)、证券(CR4 35-50%+增速受周期影响) |
| 成长后期→成熟期（特殊） | CR4≥50% + 渗透率50-60% + 存量竞争                              | 按存量竞争特殊规则归成熟期                                                  | 按成熟期估值，关注龙头份额提升和分红能力                                   | 汽车整车(CR4>65%+渗透率51.5%)、光伏设备(CR5达76%+装机-31%)                                        |
| 初创期→成长期           | 营收增速从>30%波动收窄至20-30%稳定 + CR4从<20%升至20-40%       | 归成长期；若CR4仍<20%且增速波动，维持初创期                                 | 归成长期后按成长期策略（优选龙头），但需持续跟踪CR4变化                    | 半导体(国产化率35%+CR3<15%但增速稳定归成长期)                                                     |
| 成熟→衰退过渡           | CR4 40-50%(同比降3-5pct) + 营收增速0~-3% + 渗透率从峰值降<2pct | 仍归成熟期，但标注"成熟→衰退过渡"；若CR4同比降≥5pct或营收<-3%，调整为衰退期 | 按成熟期防守策略（高股息/现金流），但需警惕衰退风险，降低仓位              | 水务运营(CR4 45%同比降4pct+营收0~-2%+渗透率峰值80%(2024)→当前78%)                                 |

> **过渡阶段标注格式**：统一为「目标阶段（过渡）」，如「成熟期（过渡）」表示当前归成熟期但由成长期过渡而来；仍归原主阶段，过渡仅为备注

**过渡阶段判定案例**：

| 行业       | 核心指标                                         | 过渡类型  | 标注           | 判定过程                                                                                        |
| ---------- | ------------------------------------------------ | --------- | -------------- | ----------------------------------------------------------------------------------------------- |
